## 2. 현재 시스템 분석

### 2.1 현재 데이터베이스 스키마

#### organization 테이블
```sql
CREATE TABLE organization (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    회사 TEXT,
    본부 TEXT,
    담당_사업단_센터 TEXT,
    실 TEXT,
    팀 TEXT,
    비고 TEXT,
    created_at TEXT,
    updated_at TEXT
)
```

#### fte 테이블
```sql
CREATE TABLE fte (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    팀명 TEXT,
    기간 TEXT,
    회사 TEXT,
    FTE_전체 REAL,
    FTE_책임 REAL,
    FTE_선임 REAL,
    FTE_사원 REAL,
    인원수_전체 INTEGER,
    인원수_책임 INTEGER,
    인원수_선임 INTEGER,
    인원수_사원 INTEGER,
    FTE_per_인원_전체 REAL,
    FTE_per_인원_책임 REAL,
    FTE_per_인원_선임 REAL,
    FTE_per_인원_사원 REAL,
    created_at TEXT,
    updated_at TEXT
)
```

#### regression_models 테이블
```sql
CREATE TABLE regression_models (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    org_name TEXT NOT NULL,
    model_type TEXT NOT NULL, -- '전사' or '팀별'
    r_squared REAL,
    adjusted_r_squared REAL,
    f_statistic REAL,
    p_value REAL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

#### regression_parameters 테이블
```sql
CREATE TABLE regression_parameters (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    model_id INTEGER NOT NULL,
    parameter_name TEXT NOT NULL,
    coefficient REAL,
    std_error REAL,
    t_statistic REAL,
    p_value REAL,
    FOREIGN KEY (model_id) REFERENCES regression_models(id)
)
```

#### team_metrics 테이블
```sql
CREATE TABLE team_metrics (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    team_name TEXT NOT NULL,
    year INTEGER,
    month INTEGER,
    metric_category TEXT,
    metric_name TEXT,
    metric_value REAL
)
```

#### team_headcount 테이블
```sql
CREATE TABLE team_headcount (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    team_name TEXT NOT NULL,
    year INTEGER,
    month INTEGER,
    position TEXT, -- '책임', '선임', '사원'
    headcount INTEGER,
    flow_logins INTEGER
)
```

### 2.2 현재 API 엔드포인트

#### 데이터 업로드 API (`/api/data/*`)
- `POST /api/data/upload` - 파일 업로드 및 분석
- `GET /api/data/current` - 현재 로드된 데이터 조회
- `GET /api/data/status` - 데이터 상태 확인
- `POST /api/data/augment` - 데이터 증강
- `POST /api/data/reset-to-master` - 마스터 데이터로 리셋

#### 조직 API (`/api/organization/*`)
- `GET /api/organization/headcount-analysis` - 조직별 적정인원 분석
- `POST /api/organization/export-recommendations` - 추천 결과 엑셀 내보내기

### 2.3 현재 데이터 흐름

```
파일 업로드 → data_service.save_uploaded_file()
           → data_service.load_data_from_file()
           → master_data 및 current_data 설정
           → pickle 파일로 저장 (master_data.pkl, working_data.pkl)
```

```typescript
// 월별 집계 데이터
interface MonthlyAggregate {
  user_id: string;
  user_name: string;
  department: string;
```

#### 1) company_wide_features (전사 인력 Feature)
```sql
CREATE TABLE company_wide_features (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    organization TEXT NOT NULL,  -- 'R*A', '통기본'
    year INTEGER NOT NULL,

    -- 외부 환경 지표
    ev_growth_gl REAL,           -- 글로벌 EV시장성장률
    v_growth_gl REAL,            -- 글로벌 자동차 시장성장률
    v_export_kr REAL,            -- 국내 자동차 수출액 증가율
    vp_export_kr REAL,           -- 국내 자동차부품 수출액 증가율
    gdp_growth_kr REAL,          -- GDP성장률
    cpi_kr REAL,                 -- 소비자물가상승률
    exchange_rate_change_krw REAL, -- 환율변화율_원화기준
    scm_index_gl REAL,           -- 글로벌물류비지수
    oil_gl REAL,                 -- 국제유가

    -- 내부 성과 지표
    revenue REAL,                -- 매출액 증감률
    profit REAL,                 -- 영업이익 증감률
    operating_rate REAL,         -- 가동률 증감률
    operating_date REAL,         -- 가동일수 증감률
    labor_cost REAL,             -- 인건비 증감률

    -- 타겟 변수
    headcount INTEGER,           -- 정원

    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    UNIQUE(organization, year)
);
```

### 7.1 주요 변경사항
