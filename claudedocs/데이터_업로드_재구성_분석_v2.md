## 1. 시스템 구조 변경 요약

### 1.1 기존 구조
```
데이터 업로드 (단일 파일)
    ↓
전사 적정인력 산정/예측 (단일 페이지)
    ↓
조직, 직급별 적정인력 산정/예측
    ↓
인력 수준 검토
```

### 1.2 새로운 구조
```
데이터 업로드 (5개 탭)
    ├─ 탭1: 전사인력-R&A           → company_wide_features (organization='R&A')
    ├─ 탭2: 전사인력-tonggibon         → company_wide_features (organization='tonggibon')
    ├─ 탭3: 조직인력               → team_features + team_feature_mapping
    ├─ 탭4: FTE분석                → fte (기존 테이블)
    └─ 탭5: 조직도                 → organization (기존 테이블)
        ↓
전사 적정인력 산정/예측 - R&A (새 페이지)
        ↓
전사 적정인력 산정/예측 - 통합기술본부 (새 페이지)
        ↓
조직, 직급별 적정인력 산정/예측 (기존 유지)
        ↓
인력 수준 검토 (기존 유지)
```

### 1.3 주요 차이점

| 항목 | 기존 | 신규 |
|------|------|------|
| 전사 페이지 수 | 1개 | 2개 (R&A, tonggibon 분리) |
| FTE 테이블 | fte (단일) | fte (그대로 유지) |
| 데이터 업로드 | 단일 파일 | 5개 탭으로 분리 |
| 조직 구분 | 없음 | organization 컬럼으로 구분 |

**라우트**: `/dashboard/company-wide/rna`

**사용 파일**: `1-1. 전사인력산정용_R&A.xlsx`

**데이터 소스**: `company_wide_features` 테이블 (WHERE organization='R&A')

**필요한 데이터 구조**:
```typescript
interface CompanyWideData {
  organization: 'R&A';
  year: number;
  features: {
    ev_growth_gl: number;        // 글로벌 EV시장성장률
    v_growth_gl: number;         // 글로벌 자동차 시장성장률
    v_export_kr: number;         // 국내 자동차 수출액 증가율
    vp_export_kr: number;        // 국내 자동차부품 수출액 증가율
    gdp_growth_kr: number;       // GDP성장률
    cpi_kr: number;              // 소비자물가상승률
    exchange_rate_change_krw: number;  // 환율변화율
    scm_index_gl: number;        // 글로벌물류비지수
    oil_gl: number;              // 국제유가
    revenue: number;             // 매출액 증감률
    profit: number;              // 영업이익 증감률
    operating_rate: number;      // 가동률 증감률
    operating_date: number;      // 가동일수 증감률
    labor_cost: number;          // 인건비 증감률
  };
  target: {
    headcount: number;           // 정원
  };
}
```

**페이지 기능**:
- R&A 조직 전용 예측 모델
- 2021~2025년 데이터 기반 학습

### 2.4 인력 수준 검토 (수정됨)

**라우트**: `/organization-headcount`

**사용 파일**: `3. FTE_analysis_20251002_151555.xlsx`

**데이터 소스**: `fte` 테이블 (기존)

**사용할 시트**: `평균FTE` 시트만 사용

**필요한 데이터 구조**:
```typescript
interface AverageFTE {
  company: string;           // 계열사 (Corp., R&A 등)
  department: string;        // 부서 (팀명)
  position: string;          // 사용자직위 (전체, 책임, 선임, 사원)
  avg_fte: number;           // 평균FTE
  headcount: number;         // 인원수
  fte_per_person: number;    // 평균FTE/인원수 (업무 강도 지표)
}
```

**기존 fte 테이블 매핑**:
```sql
-- 기존 fte 테이블 구조 (그대로 사용)
CREATE TABLE fte (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    팀명 TEXT,
    기간 TEXT,
    회사 TEXT,
    FTE_전체 REAL,            -- avg_fte (전체)
    FTE_책임 REAL,            -- avg_fte (책임)
    FTE_선임 REAL,            -- avg_fte (선임)
    FTE_사원 REAL,            -- avg_fte (사원)
    인원수_전체 INTEGER,      -- headcount (전체)
    인원수_책임 INTEGER,      -- headcount (책임)
    인원수_선임 INTEGER,      -- headcount (선임)
    인원수_사원 INTEGER,      -- headcount (사원)
    FTE_per_인원_전체 REAL,   -- fte_per_person (전체) ⭐
    FTE_per_인원_책임 REAL,   -- fte_per_person (책임) ⭐
    FTE_per_인원_선임 REAL,   -- fte_per_person (선임) ⭐
    FTE_per_인원_사원 REAL,   -- fte_per_person (사원) ⭐
    created_at TEXT,
    updated_at TEXT
)
```

**업무 강도 지표 해석**:
- `FTE_per_인원_*` 컬럼 활용
- 1.0 ~ 1.1: 적정 업무량
- 1.1 ~ 1.3: 다소 과부하
- 1.3 초과: 심각한 과부하 (인력 충원 필요)
- 1.0 미만: 업무량 여유

**페이지 기능**:
- 팀별, 직위별 업무 강도 시각화
- 과부하 팀 자동 식별
- 적정 인력 추천 (FTE_per_인원 → 1.0~1.1로 조정)

## 3. 데이터베이스 스키마 (수정)

### 3.1 새로 추가할 테이블 (2개만)

#### 1) company_wide_features (전사 인력 Feature)
```sql
CREATE TABLE company_wide_features (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    organization TEXT NOT NULL,  -- 'R&A' 또는 'tonggibon'
    year INTEGER NOT NULL,

    -- 외부 환경 지표 (10개)
    ev_growth_gl REAL,           -- 글로벌 EV시장성장률
    v_growth_gl REAL,            -- 글로벌 자동차 시장성장률
    v_export_kr REAL,            -- 국내 자동차 수출액 증가율
    vp_export_kr REAL,           -- 국내 자동차부품 수출액 증가율
    gdp_growth_kr REAL,          -- GDP성장률
    cpi_kr REAL,                 -- 소비자물가상승률
    exchange_rate_change_krw REAL, -- 환율변화율_원화기준
    scm_index_gl REAL,           -- 글로벌물류비지수
    oil_gl REAL,                 -- 국제유가

    -- 내부 성과 지표 (5개)
    revenue REAL,                -- 매출액 증감률
    profit REAL,                 -- 영업이익 증감률
    operating_rate REAL,         -- 가동률 증감률
    operating_date REAL,         -- 가동일수 증감률
    labor_cost REAL,             -- 인건비 증감률

    -- 타겟 변수
    headcount INTEGER,           -- 정원

    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    UNIQUE(organization, year)
);

CREATE INDEX idx_company_org ON company_wide_features(organization);
CREATE INDEX idx_company_year ON company_wide_features(year);
```

**데이터 예시**:
```sql
-- R&A 데이터
INSERT INTO company_wide_features (organization, year, ev_growth_gl, v_growth_gl, ..., headcount)
VALUES ('R&A', 2021, 1.04, 0.026, ..., 320);

-- tonggibon 데이터
INSERT INTO company_wide_features (organization, year, ev_growth_gl, v_growth_gl, ..., headcount)
VALUES ('tonggibon', 2021, 1.04, 0.026, ..., 250);
```

```python
def validate_fte_file(file_path):
    """FTE 파일 검증 - 평균FTE 시트만 확인"""
    xls = pd.ExcelFile(file_path)

    # 1. 평균FTE 시트 존재 확인
    if '평균FTE' not in xls.sheet_names:
        raise ValueError("필수 시트 '평균FTE'를 찾을 수 없습니다")

    # 2. 평균FTE 시트 읽기
    df = pd.read_excel(file_path, sheet_name='평균FTE')

    # 3. 필수 컬럼 확인
    required_columns = ['계열사', '부서', '사용자직위', '평균FTE', '인원수', '평균FTE/인원수']
    missing_columns = [col for col in required_columns if col not in df.columns]
    if missing_columns:
        raise ValueError(f"필수 컬럼 누락: {missing_columns}")

    # 4. 데이터 타입 검증
    if not pd.api.types.is_numeric_dtype(df['평균FTE']):
        raise ValueError("'평균FTE' 컬럼은 숫자 타입이어야 합니다")
    if not pd.api.types.is_numeric_dtype(df['인원수']):
        raise ValueError("'인원수' 컬럼은 숫자 타입이어야 합니다")
    if not pd.api.types.is_numeric_dtype(df['평균FTE/인원수']):
        raise ValueError("'평균FTE/인원수' 컬럼은 숫자 타입이어야 합니다")

    # 5. 값 범위 검증
    if (df['평균FTE'] < 0).any():
        raise ValueError("'평균FTE' 값은 0 이상이어야 합니다")
    if (df['인원수'] < 0).any():
        raise ValueError("'인원수' 값은 0 이상이어야 합니다")

    # 6. 업무 과부하 팀 식별
    overloaded = df[df['평균FTE/인원수'] > 1.3]
    warnings = []
    if len(overloaded) > 0:
        warnings.append(f"⚠️ 과부하 팀 {len(overloaded)}개 발견 (FTE/인원 > 1.3)")

    return {
        'is_valid': True,
        'rows': len(df),
        'companies': df['계열사'].unique().tolist(),
        'departments': df['부서'].nunique(),
        'warnings': warnings,
        'data': df
    }
```

```python
def save_fte_data(df):
    """평균FTE 데이터를 fte 테이블에 저장"""
    conn = get_db_connection()
    cursor = conn.cursor()

    # 기존 데이터 삭제 (또는 UPSERT)
    cursor.execute("DELETE FROM fte")

    # 평균FTE 데이터를 fte 테이블 구조에 맞게 변환
    # 각 팀/회사별로 전체, 책임, 선임, 사원을 하나의 row로 합침
    teams = df.groupby(['계열사', '부서'])

            fte_data['FTE_전체'], fte_data['FTE_책임'], fte_data['FTE_선임'], fte_data['FTE_사원'],
```
